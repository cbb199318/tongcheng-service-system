SpringBoot + Vue2 + MyBatis-Plus

同城服务管理系统

论文配套演示版，覆盖用户端、商家端、管理端三大门户，并为积分、服务沟通、人员招募预留扩展入口。

用户端

注册登录、浏览服务、预约下单、模拟支付、订单管理、服务评价、商家入驻。

商家工作台

商家与员工共用一个入口登录，支持店铺维护、员工管理、订单处理、评价回复与内部履约协同。

管理端

用户管理、审核管理、内容管理、订单监管与统计面板。
演示账号：`user01 / 123456`、`merchant01 / 123456`、`staff1_1 / 123456`、`admin / 123456`
员工账号请从商家工作台进入，登录页切换到“员工登录”。
后端默认地址：`http://localhost:8080`
